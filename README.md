# Инструмент визуализации графа зависимостей для менеджерапакетов.
Было разработано CLI-приложение на Java 17 при помощи Maven.
## Конфигурация

Настройки берутся из `config.yaml`: `package_name` (строго `groupId:artifactId:version`),
`repository_url` (HTTPS), `output_file` (PNG),
`filter` (подстрока в `artifactId`), необязательный `max_packages` (защита от слишком большого обхода).
Путь к YAML можно передать первым аргументом командной строки.
## Как устроен алгоритм

1. `ConfigLoader` читает и проверяет настройки.
2. `GraphBuilder` кладёт корень в очередь и рекурсивно повторяет один шаг BFS.
3. `MavenClient` скачивает XML текущего POM при помощи `HttpClient`.
4. `PomParser` получает из POM прямые зависимости при помощи DOM, дополнительно читает parent, dependencyManagement и импортированные BOM и сообщает источник найденной версии.
5. `DependencyGraph` запоминает **все** найденные рёбра и вершины.
6. `MermaidVisualizer` превращает список смежности в текст `flowchart TD`,
   записывает `.mmd` и вызывает внешнюю команду `mmdc` для PNG.
